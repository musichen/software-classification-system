By autonomy
A useful modern spectrum is:
Level 0 — passive software
Human performs everything.
↓
Level 1 — assisted
Autocomplete, suggestions.
↓
Level 2 — automated
Rules and workflows.
↓
Level 3 — agentic
Software decides how to accomplish a task.
↓
Level 4 — autonomous
Software works continuously toward objectives.
↓
Level 5 — self-evolving
Software can create or modify its own tools, plugins, workflows, or interfaces.

The highest-level taxonomy
almost all software fits into roughly 16 fundamental families:
	1. System software 
	2. Application software 
	3. Developer software 
	4. Data software 
	5. AI / agent software 
	6. Infrastructure / cloud software 
	7. Networking software 
	8. Security software 
	9. Business / enterprise software 
	10. Scientific / engineering software 
	11. Creative / media software 
	12. Industrial / embedded software 
	13. Communication / collaboration software 
	14. Consumer / entertainment software 
	15. Domain-specific vertical software 
	16. Meta-software — software that creates/manages other software 
And increasingly I would add a 17th fundamental family:
17. Autonomous / self-evolving software
This includes agents, software factories, adaptive applications, generative UIs and systems capable of dynamically creating their own tooling.
That category is likely to become as important as “application software” or “developer software” over the next decade.
