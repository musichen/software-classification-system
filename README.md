# Software Classification System

A universal registry of software types, kinds, and classes.

One exhaustive list of **100 categories**. Each category has subcategories plus example software: official product URLs and curated lists of related software.

Source taxonomy: [`100categories-of-software.md`](100categories-of-software.md). Original curated inventory (Awesome lists) is merged into these categories. Entries that are not a software class stay in [Original inventory not assigned to a software class](#original-inventory-not-assigned-to-a-software-class).

## How to read a category

- **Subcategories** - finer types within the class
- **Example software** - representative products and platforms with official URLs
- **Curated lists** - assigned entries from the original inventory (usually Awesome lists of software in this class)

## Highest-level families

Almost all of the 100 categories sit in these families:

1. System software

16. Meta-software - software that creates or manages other software
17. Autonomous / self-evolving software

## 1. System software

Software whose primary purpose is to operate, control, virtualize, or provide foundational services for computing hardware.

### Subcategories

- **Operating systems:** Desktop OS, Server OS, Mobile OS, Embedded OS, Real-time OS, Mainframe OS, Network OS, Distributed OS, Cloud-native OS, Hypervisor OS, Appliance OS
- **Kernels:** Monolithic kernels, Microkernels, Hybrid kernels, Exokernels, Unikernels, Real-time kernels
- **Device drivers:** GPU drivers, Audio drivers, Printer drivers, Storage drivers, Network drivers, USB drivers, Sensor drivers, Camera drivers, Human-interface-device drivers
- **Firmware:** BIOS / UEFI, Router firmware, SSD firmware, Device firmware, IoT firmware, Embedded controller firmware, Baseboard management firmware, Automotive ECU firmware
- **Boot software:** Bootloaders, Secure boot systems, OS installers, Recovery environments, PXE/network boot systems
- **System utilities:** File managers, Disk utilities, Backup tools, Compression tools, System monitors, Process managers, Clipboard utilities, Search/indexing tools, Package managers, System cleanup tools, Configuration tools

- [Windows](https://www.microsoft.com/windows) - Desktop / server OS

- [macOS](https://www.apple.com/macos) - Desktop OS

- [iOS](https://www.apple.com/ios) - Mobile OS
- [FreeBSD](https://www.freebsd.org) - Unix-like OS
- [QNX](https://blackberry.qnx.com) - Real-time OS
- [GRUB](https://www.gnu.org/software/grub) - Bootloader
- [systemd](https://systemd.io) - System and service manager

### By autonomy

A useful modern spectrum:

- Level 0 - passive software. Human performs everything.
- Level 1 - assisted. Autocomplete, suggestions.
- Level 2 - automated. Rules and workflows.
- Level 3 - agentic. Software decides how to accomplish a task.
- Level 4 - autonomous. Software works continuously toward objectives.
- Level 5 - self-evolving. Software can create or modify its own tools, plugins, workflows, or interfaces.
